# Spacing

> 基准单位 4px（2px 仅作标签半步）。来源：3 个完整到达屏的 auto-layout 间距统计（4 ×139、10 ×125、8 ×120、3 ×102、6 ×99、12 ×34、2 ×32、5 ×29、16 ×5）。
> 已确认：页边距由 18 统一为 16；零碎值 3 → 2、5 → 4；10 只作组件专用值。

## Primitives

`0, 2, 4, 6, 8, 12, 16, 24, 32`

## Semantic Tokens

### Scale

| Token | Value | 用途 | 依据 |
|---|---|---|---|
| `space/2xs` | 2px | 标签上下内边距、图标与 10px 小字之间 | 观测 2/4 ×41；原 3px（×102）吸附至此 |
| `space/xs` | 4px | 图标↔文字、元信息之间（古建登楼 · ¥40/人）、标签左右内边距 | 观测 ×139；原 5px（×29）吸附至此 |
| `space/sm` | 6px | 卡片内文字行之间（标题→元信息→标签） | 观测 ×99（卡片内容区 gap 6） |
| `space/md` | 8px | 区块标题→内容、图片卡内边距、列表行之间 | 观测 ×120 |
| `space/lg` | 12px | 横滑卡片之间、列表卡内行间距 | 观测（Recommendation 横滑 gap 12） |
| `space/xl` | 16px | 区块与区块之间 | 观测：3 屏区块间距均为 16 |
| `space/2xl` | 24px | 页面顶部信息区 → 首个内容区（预留） | 扩展，未观测 |

### Layout

| Token | Value | 用途 | 依据 |
|---|---|---|---|
| `layout/page-margin` | 16px | 页面左右安全边距 | 已确认由 18 统一为 16，与 xl 对齐 |
| `layout/section-gap` | 16px | 区块与区块之间（= xl） | 观测 |
| `layout/section-title-gap` | 8px | 区块标题 → 区块内容（= md） | 观测 |
| `layout/carousel-gap` | 12px | 横滑卡片之间（= lg） | 观测 |

### Component-only（不进通用阶梯）

| Token | Value | 用途 | 依据 |
|---|---|---|---|
| `component/control-padding-x` | 10px | 按钮、服务入口胶囊左右内边距 | 观测 9/10 ×21、gap 10 ×125；只限组件内，不进通用阶梯 |
| `component/control-padding-y` | 8px | 按钮上下内边距（9 → 8） | 观测 9，吸附到 4 的倍数 |
| `component/card-inset-x` | 14px | 列表卡左右内边距（今晚末班车时间卡） | 观测 8/14/8/14；组件专用 |
| `component/tag-padding` | 2 / 4px | 标签内边距（上下 / 左右） | 观测 2/4 ×41 |

## Usage Rules

- 页面结构只用 `layout/*`：左右 16、区块之间 16、标题到内容 8、横滑卡片之间 12。
- 卡片和列表内部用 `space/2xs`–`space/lg`；层级越外，间距越大（标签内 2 → 文字行 6 → 卡片内边距 8 → 卡片之间 12 → 区块之间 16）。
- 不再使用 3、5、9、18 等零碎值：3 → 2，5 → 4，9 → 8，18 → 16。
- `10` 与 `14` 只允许出现在 `component/*` 定义的组件里（按钮、胶囊、列表卡），不得在页面布局中引用。
- `space/2xl`（24）为扩展预留，当前稿未使用。
