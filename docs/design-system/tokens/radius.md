## Usage Rules

- **嵌套圆角递减**：容器（16）> 内容卡（12）> 卡内图片（8）> 按钮（4）> 标签（2）。内层圆角不得大于外层。
- `component`（12）用于**承载单个 POI 的内容卡**；`container`（16）用于**承载一组列表或整块浮层**。两者不混用：同一层级的卡片必须同一圆角。
- 按钮一律 `control`（4），不做胶囊按钮；胶囊 `pill` 只给服务入口和图片角标。
- `shape/ranking-tag` 是扫街榜的视觉识别，只用于扫街榜标签，不得用于普通标签。
- 不再出现 1、1.6、3、5、10、17.5 等零碎圆角。
